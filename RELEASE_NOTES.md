# Sajilo Pharmacy 1.0.0 — Windows Installer

Offline pharmacy management for Nepal: billing, medicines & batches, expiry
tracking, khata, purchases, patients, expenses, reports and thermal receipts.

## Download

**`Sajilo Pharmacy Setup 1.0.0.exe`** — Windows 10 / 11 (64-bit), ~119 MB.

## Highlights

- **Fast POS billing** with generic/brand/manufacturer search and keyboard shortcuts
- **Batch & expiry tracking (FEFO)** — expired medicine is blocked at billing
- **Digital khata** with due aging and WhatsApp reminders
- **DDA-ready thermal invoices** (58 mm / 80 mm) with pharmacist and PAN details
- **Purchases, suppliers, free quantities (10+1), expenses** and profit reports
- **100% offline** — your data never leaves the shop
- **30-day free trial**, then a one-time lifetime license per PC

## Install

1. Download the installer above.
2. Run it (Windows SmartScreen → **More info → Run anyway**).
3. Open **Sajilo Pharmacy**, register your pharmacy and start billing.
4. After the trial, activate with a license key from the seller.

## Notes

- Your database lives in `%APPDATA%\Sajilo Pharmacy\data`.
- Backups: **Settings → Backup**. Restore from the same screen.
- License activation: **Settings → License** (copy the Machine ID and send it to the seller).
